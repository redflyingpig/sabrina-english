# Sabrina English 大型日常英语内容库设计

## 目标

把目前写在 `index.html` 里的小型课程数组替换为可维护、可验证的独立内容库。内容聚焦日常生活 A1–B2，满足长期学习和连续追加批次的需要，同时保持 Sabrina English 是一个轻量个人工具。

目标容量：

- 至少 4,000 个唯一单词；
- 至少 600 条日常表达；
- 至少 250 个实用句型；
- 单词覆盖 A1、A2、B1、B2，不加入 C1、学术专有词或冷僻词。

## 内容边界与质量

单词以日常沟通为主，覆盖家庭、学校、工作、购物、饮食、健康、交通、旅行、天气、住房、人际关系、娱乐、数字生活和公共服务等主题。

每个单词包含：

- 稳定且唯一的 `id`；
- 英文词形；
- CEFR 等级；
- 主题；
- 音标；
- 简明中文释义；
- 一句自然、适合该等级的原创英文例句。

每条表达包含稳定 ID、CEFR 等级、主题、英文表达、中文使用说明和原创例句。每个句型包含稳定 ID、CEFR 等级、主题、句型、中文说明和三句原创例句。

Oxford、Cambridge 和 British Council 的公开学习范围只用于判断常用程度、CEFR 和主题覆盖；不复制其释义或例句。本站的中文释义和英文例句独立编写。

## 文件结构

内容与程序分离，使用版本化静态 JSON：

```text
content/
  manifest.json
  vocabulary-a1.json
  vocabulary-a2.json
  vocabulary-b1.json
  vocabulary-b2.json
  expressions.json
  patterns.json
```

`manifest.json` 记录内容版本、各文件条目数和校验摘要。Python 服务只公开 `index.html` 和这些明确列入白名单的内容文件，继续禁止访问仓库其他文件。

浏览器首次打开时加载 manifest 和课程所需内容。一次性加载整个内容库的预计体积仍适合个人网站；如果最终文件明显超过合理范围，则按等级分片并在后台预取下一片，不引入数据库内容表或新的内容 API。

## 课程抽取

课程批次保持现有大小：

- 单词模式：5 个；
- 表达模式：3 个；
- 句型模式：1 个。

内容不再预先固定成小组。客户端根据稳定内容 ID 动态组成批次：

1. 使用“档案名 + 内容版本 + 模式”生成稳定打乱顺序；
2. 当天的起始位置由日期和该模式出现次数决定；
3. 优先跳过该档案历史中已经学过的稳定 ID；
4. 当前批次全部完成后显示“再学一组”；
5. 点击后继续同一模式，并从后续未学内容组成新批次；
6. 刷新页面后根据历史与稳定顺序恢复到合理的未学批次，不随机跳回旧内容；
7. 只有整个模式内容都学习过以后才允许重复，并优先选择最久未复习的内容。

单词达到 4,000 个后，即使每天额外学习多个批次，也不会在短期内被迫重复。

## 学习记录兼容

新记录写入 `contentId`，同时保留现有 `key`、`favoriteKey`、标题、释义和例句快照，保证历史展示和导出文件是自包含的。

旧记录没有 `contentId` 时，客户端用模式和标准化英文标题匹配新内容；匹配不到也保留旧记录，不丢数据。服务端学习状态结构和 SQLite schema 不需要改变。

## 失败与离线行为

- 内容文件加载失败时显示明确的重试状态，不清除学习记录。
- 已加载页面断网后，当前内容、标记学习、收藏和复习仍能工作；恢复网络后按现有机制同步。
- 内容版本升级不会重置用户历史；稳定 ID 一旦发布不得复用给不同内容。
- 单个坏条目不得让整个页面崩溃。构建时验证会阻止坏内容进入生产。

## 界面

- “再学一组”只在当前批次完成后出现，加载后保持相同模式。
- 如果内容池确实耗尽，按钮改为引导复习，不假装提供“新”内容。
- 导入和导出继续使用已经确认的紧凑按钮布局。
- 手机和桌面保持现有响应式布局，不增加内容筛选、排行榜或管理后台。

## 验证

新增内容验证脚本和测试，至少检查：

- 单词不少于 4,000、表达不少于 600、句型不少于 250；
- ID、单词、表达和句型在各自范围内唯一；
- 必填字段、字段类型和 CEFR 只允许 A1–B2；
- 音标、中文释义和例句非空；
- 批次大小正确，同一批次无重复；
- 用户仍有未学内容时不会返回已学内容；
- “再学一组”保持当前模式；
- 旧学习记录仍能显示、同步、导入和导出；
- 内容静态白名单不会重新暴露 `.git` 或后端文件；
- 桌面与手机正式域名的登录、学习、下一批和同步流程通过。

## 明确不做

- 不在运行时调用 AI 生成课程；
- 不加入第三方内容服务或 API key；
- 不把课程内容放入 SQLite；
- 不增加搜索、测验系统、后台编辑器或复杂个性化算法；
- 不复制受版权保护的词典释义和例句。
