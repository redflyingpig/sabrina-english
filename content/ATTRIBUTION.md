# Sabrina English content attribution

Runtime content files are generated and validated before deployment. Production does not call an external dictionary, content API, or AI service.

## Vocabulary source

- Project: ECDICT by skywind3000
- Source: <https://github.com/skywind3000/ECDICT>
- License: MIT
- Pinned revision: `82c9872576b23118d7c42e920c11beb77f510ae2`
- Build input: `ecdict.csv`
- SHA-256: `1a6947e04785db63613a92e14903cdae7954f7e84860b10e68e5c7cbb3f9c3cf`

The build script verifies the checksum, selects 4,000 high-frequency entries with phonetics and Chinese translations, rejects capitalized proper nouns and name markers, assigns an approximate A1–B2 study band, and emits stable IDs. Source dictionary example sentences are not copied. The short learning-context sentences are original templates generated by this project.

## Expressions and patterns

The expression and sentence-pattern catalogs, Chinese usage notes, and examples are original project content assembled deterministically from the templates in `scripts/example_templates.py`.
